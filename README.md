# Moving to Singapore — A Family Guide

A static, bilingual (English/한국어) relocation guide for a Korean family moving to Singapore — first-30-days checklist, preschool and primary-school paths, neighbourhood comparison with an interactive map, Korean community resources, helper hiring, the car question, and a monthly budget. Plain HTML/CSS/vanilla JS with no build step (Leaflet is vendored in `assets/leaflet/`; the "Real map" tab needs internet for OSM/CARTO tiles, everything else works offline): open `index.html` directly to use it locally, and deploy to Vercel with zero config — either run `npx vercel` from this folder (accept the defaults; no framework, no build command, output directory `.`), or push the repo to GitHub and import it at vercel.com/new, where Vercel auto-detects it as a static site. All figures come from `CONTENT.md` (researched August 2026) and should be re-verified before big decisions.
